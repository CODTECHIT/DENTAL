| **H2 #6** | `What Our Patients Say` | Reviews block |
| **H2 #7** | `Dental FAQs — Tukkuguda Patients Ask` | FAQ accordion (matches FAQPage schema) |
| **H2 #8** | `Visit Sri Shobh Dental — Directions & Contact` | Contact/map block with NAP + hours |
| **H3** | `Opening Hours`, `Emergency Dental Care`, `Book an Appointment` | Sub-blocks of contact |
| **H6** | Service card micro-captions / image captions | Only where content semantics require |

**Hierarchy rules for the whole site:**
1. One H1 per page = the page's primary target keyword + brand.
2. H2 = main content blocks; H3 = sub-blocks; H4–H6 only when a section genuinely nests deeper (FAQ questions, service sub-specs).
3. Never skip levels (no H1 → H3). Keep visual styling independent of tag level.
4. Blog posts: H1 = post title (with keyword), H2 = each question/subtopic, H3 = sub-details.
